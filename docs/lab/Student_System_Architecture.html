Student Information System Architecture

Users   Student · Teacher · Administrator
Each user opens the system on a phone, tablet, or computer.

PRESENTATION LAYER

User Interface

Laravel Blade pages rendered as HTML in the browser. Users submit registration, enrollment, and grading forms.

Network connection
HTTP(S) request→←HTML response
APPLICATION LAYER

Application Server

Laravel routes requests, validates input, and applies business rules.

Authentication Module
Sessions, password hashing, CSRF protection, and role and record access checks.

Database connection
Eloquent / SQL→←Rows or result
DATA LAYER

Database Server

MySQL stores users, students, teachers, subjects, enrollments, and grades. Constraints maintain record integrity.

Registration   The browser posts the form. Laravel validates it and saves the user and student in one transaction. After MySQL commits both rows, Laravel redirects to a page that confirms registration.

Hardware   A user device and a host running Laravel and MySQL. The servers can share one physical host for the lab.
